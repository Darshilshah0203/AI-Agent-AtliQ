# Privacy policy: AtliQ AI Agent

AtliQ AI Agent is a personal learning project built in the Codebasics Data Analytics Bootcamp. It runs
on one person's own computer and is used only by that person.

## What the app accesses

- **Google Docs (read only):** it reads the text of the stakeholder brief documents that are stored in
  the app owner's own Google account. It cannot edit, create or delete any document.
- **Gmail (send only):** it sends report emails from the app owner's own Gmail account. It cannot read,
  search or delete any email.

## What it does with that data

- The text of a brief is used only to write that week's report, on the owner's computer.
- Nothing is sold, shared or sent to anyone other than the report's recipients.
- No data is stored on any server run by this project.

## Removing access

The account owner can remove the app's access at any time at
https://myaccount.google.com/permissions.

## Contact

Questions: use the contact email shown on the app's Google consent screen.
