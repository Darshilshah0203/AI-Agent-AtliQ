# Terms of service: AtliQ AI Agent

AtliQ AI Agent is a personal learning project built in the Codebasics Data Analytics Bootcamp. It is
not a commercial product or a public service.

## Who can use it

Only the owner of the Google account that set it up. Nobody else can sign in to it.

## What it does

It reads stakeholder brief documents from the owner's Google Docs and sends report emails from the
owner's Gmail, as described in the [privacy policy](PRIVACY.md).

## No warranty

The app is provided as is, for learning. It works on fictional AtliQ Hardware data. Reports it produces
should be checked by a person before anyone acts on them.

## Changes and removal

These terms can change as the project changes. The owner can stop the app at any time by removing its
access at https://myaccount.google.com/permissions.
